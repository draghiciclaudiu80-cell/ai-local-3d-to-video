Assistant

Laya — fast decisions (the real Laya)

Laya (Convai Innovations, open source, Apache 2.0) is a 421M decision model — System 1. It never writes text: it reads your message and decides what you want (a picture, a 3D model, a search, just talking…) in a fraction of a second on the processor, with how sure it is. Sure → it acts. Not sure → the main model decides, or you get buttons to choose — and every button you click teaches it how you say things. English uses the fine-tuned decision model, Romanian and other languages the multilingual one. It uses ~1–2 GB of RAM while it works and stops after 10 idle minutes.

Security

The rule: the AI may read untrusted information (web pages, files, tool results), but untrusted information can never give it authority. The AI only proposes — this app decides, and you approve anything risky.
Security log (latest events)

Internet

Searches, pages, pictures and videos go through the Tor network: websites don't see your address, each search takes a new route, and if Tor isn't connected nothing is sent. The app's window itself never goes online.
