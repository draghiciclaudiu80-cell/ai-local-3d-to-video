# Security

AI Local runs only on your PC: its server listens on 127.0.0.1, the web is off until you switch it on (and then goes
through Tor), files it downloads land in a sandbox and are never opened or run, and web pages / documents are always
treated as data, never as instructions.

Found a security problem? Please open an issue **without** the details first (or use GitHub's private
"Report a vulnerability" button on the Security tab), and I'll get back to you.
